<h1 align="center">Municipal software cities can actually own.</h1>

<p align="center">
  Townlight is an open-source, local-first municipal operations suite. One Windows installer brings records, meetings, municipal code, public notices, accessibility workflows, and the shared platform onto the city's own hardware—without a vendor cloud, telemetry, or per-seat pricing.

> **Honest status:** Townlight Records + Meetings + Code + Zoning 1.4.0-beta.1 is a bounded Windows public beta published October 21, 2026. Records-only is the default; select `zoning-beta` for the connected four-product workflow. The `city-core` profile excludes Zoning. It is ready for hands-on evaluation, but it is **not production-, city-, or procurement-ready**. The broader module catalog includes queued, foundation, and planned work; repository count is not product maturity. [Read the module-by-module status.](https://github.com/townlight/townlight/blob/main/STATUS.md)

### Why local-first

- **City-held data.** Documents, audit history, the database, and the AI model stay on the municipality's hardware.
- **Clerk-first workflows.** The active suite starts with records, meetings, code, notices, and accessible public information.
- **Human authority.** AI can draft and assist; humans decide. Townlight does not auto-release, auto-deny, auto-redact, or make legal determinations.
- **Open foundations.** Code is AGPL-3.0; documentation is CC BY 4.0. Cities retain the right to inspect, modify, operate, and fork the software.
