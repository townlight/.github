# Contributing

This repository owns Townlight's organization profile and concise routing documents. The organization front door at <https://townlight.github.io/> is maintained in [`townlight/townlight.github.io`](https://github.com/townlight/townlight.github.io). Product behavior, installer details, module documentation, architecture decisions, and current status belong in the [Townlight umbrella repository](https://github.com/townlight/townlight) or the relevant module repository.

## Make a profile change

1. Create a topic branch.
2. Update `profile/README.md` or the concise routing documents in `docs/`.
3. Confirm every changing product claim against the umbrella repository.
4. Open a pull request that identifies the authoritative source for any changed version, status, requirement, or maturity claim.

For product contributions, bug routing, and security reporting, use the [suite contribution guide](https://github.com/townlight/townlight/blob/main/CONTRIBUTING.md).
