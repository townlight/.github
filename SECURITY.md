# Security reporting

For a vulnerability in any Townlight product, report privately through the [Suite security advisory form](https://github.com/townlight/townlight/security/advisories/new). Include the affected product/version, reproduction steps and impact; do not post credentials or city data in a public issue. Maintainers will route the report to the affected component. Existing repository-specific policies remain applicable.

Current releases and their acceptance limits are documented at [Townlight releases](https://github.com/townlight/townlight/releases). Historical releases remain available as evidence; availability does not mean current support.
