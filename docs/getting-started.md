# Getting started with Townlight on Windows

1. Read the [suite operating manual](https://townlight.github.io/manuals/suite.html) and the [staff guide](https://townlight.github.io/manuals/windows-staff-workflows.html).
2. Download the signed x64 MSI for **Windows 1.9.3.2** from the [release catalog](https://github.com/townlight/townlight/releases/tag/townlight-windows-v1.9.3.2). Verify the MSI SHA-256 is `b00510e0649552b5efd9744513bf9fcaf59cbee5755fd864eb922a5151c96b77` against the [release checksums](https://github.com/townlight/townlight/releases/download/townlight-windows-v1.9.3.2/SHA256SUMS-Windows-1.9.3.2.txt) and check its signature against the [signing evidence](https://github.com/townlight/townlight/releases/download/townlight-windows-v1.9.3.2/Signing-Evidence-Windows-1.9.3.2.txt). Review the [acceptance summary](https://github.com/townlight/townlight/releases/download/townlight-windows-v1.9.3.2/ACCEPTANCE-Windows-1.9.3.2.md) for tested artifacts and limits.
3. For a fresh install, complete first setup: create the named administrator, choose backup storage, run Health Check, and finish setup. If shown, prepare Records. Bundled Station can be provisioned during first-run; a physical camera requires a signed-in Windows session.
4. For the tested direct upgrade from Windows 1.9.3.1 to 1.9.3.2, back up city data and settings first. Preserve `%LOCALAPPDATA%\CivicSuite` for compatibility. Close the app, run the MSI, and confirm it reopens the same account/profile.
5. Add named staff using existing roles. Shared host/workstation configuration and separate resident-portal configuration remain explicit setup choices; they are not enabled implicitly.
6. If the city records meetings, enable bundled Station in setup and verify camera and microphone preview using the [Station manual](https://townlight.github.io/manuals/station.html).

Windows 1.9.3.2 passed exact signed fresh-install, lifecycle, and adjacent-upgrade checks. Earlier evidence is retained; these checks do not imply that every workflow was retested.
