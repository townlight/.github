# Getting started with Townlight on Windows

1. Read the [suite operating manual](https://townlight.github.io/manuals/suite.html).
2. Download the signed x64 MSI from the [Windows 1.9.2.1 release](https://github.com/townlight/townlight/releases/tag/townlight-windows-v1.9.2.1). Verify its SHA-256 against the [release checksums](https://github.com/townlight/townlight/releases/download/townlight-windows-v1.9.2.1/SHA256SUMS-Windows-1.9.2.1.txt) and check its signature against the [signing evidence](https://github.com/townlight/townlight/releases/download/townlight-windows-v1.9.2.1/Signing-Evidence-Windows-1.9.2.1.txt).
3. Set up a test profile, create the named administrator, choose backup storage, and complete health verification. The Windows 1.9.2.1 acceptance does not cover direct upgrades from earlier releases. Back up city data and settings before any existing-city change; keep a recovery path.
4. Add named staff. If the city records meetings, enable bundled Station in setup and verify camera and microphone preview using the [Station manual](https://townlight.github.io/manuals/station.html).

For revisioned council packets, shared staff and unattended delivery of approved artifacts, follow the [Windows 1.9.2.1 release guide](https://townlight.github.io/manuals/windows-1.9.2.1-candidate.html) and its [acceptance limits](https://github.com/townlight/townlight/releases/download/townlight-windows-v1.9.2.1/ACCEPTANCE-Windows-1.9.2.1.md). Shared mode requires explicit host and workstation configuration. Acceptance used a Windows Sandbox guest on the same physical machine as the host; it does not establish a separate physical workstation or live city network.
