# Getting started with Townlight on Windows

1. Read the [suite operating manual](https://townlight.github.io/manuals/suite.html).
2. Download the signed x64 MSI from the [Windows 1.9.1.1 release](https://github.com/townlight/townlight/releases/tag/townlight-windows-v1.9.1.1). Verify the SHA-256 and Authenticode signature against the release evidence.
3. For a new installation, create the city profile and named administrator, choose backup storage, and complete health verification. For an upgrade from 1.9.0.1, back up city data and settings, close Townlight, and keep the existing Windows account and profile. Check the [acceptance summary](https://github.com/townlight/townlight/releases/download/townlight-windows-v1.9.1.1/ACCEPTANCE-Windows-1.9.1.1.md) for the build used for each upgrade check.
4. Add named staff. If the city records meetings, enable bundled Station in setup and verify camera and microphone preview using the [Station manual](https://townlight.github.io/manuals/station.html).

For council packet revisions, shared staff PCs and unattended delivery of approved artifacts, see the [Windows 1.9.2.1 candidate walkthrough](https://github.com/townlight/townlight/blob/main/docs/installer/operator-walkthrough.md). The signed candidate has not been released.
