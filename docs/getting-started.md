# Getting started — Townlight Beta 1

1. Read the [suite operating manual](https://townlight.github.io/manuals/suite.html) and its installation and recovery procedures.
2. Download the signed Windows MSI and exact source/documentation companions from the [Beta 1 release](https://github.com/townlight/townlight/releases/tag/townlight-beta-1-station-delivery). Compare SHA256SUMS.txt and the publisher signature before installation.
3. Use a fresh Windows x64 test installation. Normal first-run creates the profile and administrator. Select the existing full `inspections-preview` composition, then explicitly activate the canonical runtime as described in the manual.
4. Add named staff and follow the applicable product manual. Station requires separate CLI/database/storage configuration and a paired Townlight HTTP service; it does not configure or replace standalone CivicCast.
5. Review the release's ACCEPTANCE.md and the documented limits. Only synthetic development acceptance is claimed; the chosen beta site's policies, source applicability, staff and equipment require commissioning.
