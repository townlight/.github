# Townlight Windows beta status

The current public MSI is **Windows 1.9.2.1**. The [release catalog](https://github.com/townlight/townlight/releases/tag/townlight-windows-v1.9.2.1) contains the signed MSI, corresponding source, checksums, signing evidence and acceptance. The MSI SHA-256 is `3242792ad6c825a5057d96c5e1d9d45fb5726ccbfba7ab24a2b428a54e63b0bf`; its [acceptance summary](https://github.com/townlight/townlight/releases/download/townlight-windows-v1.9.2.1/ACCEPTANCE-Windows-1.9.2.1.md) names the tested artifacts and limits.

Windows 1.9.2.1 adds revisioned council packets, shared Meetings and Records work between a city host and workstation, and unattended delivery of explicitly approved packets and recordings to a configured resident portal. Acceptance used synthetic data on a physical Windows host and a clean Windows Sandbox guest on the same machine. Cold recovery used a fresh profile on the original host and account. The evidence does not establish direct upgrades from earlier releases, a separate physical workstation or replacement computer, a live city network or production portal.

The previous signed [Windows 1.9.1.1 release](https://github.com/townlight/townlight/releases/tag/townlight-windows-v1.9.1.1) and its [acceptance summary](https://github.com/townlight/townlight/releases/download/townlight-windows-v1.9.1.1/ACCEPTANCE-Windows-1.9.1.1.md) retain their original identities and evidence. The [suite manual](https://townlight.github.io/manuals/suite.html) covers the coordinated products and supporting modules. Standalone CivicCast retains its own installation and data.
