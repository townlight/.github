The current public MSI is **Windows 1.9.3.2**. The [release catalog](https://github.com/townlight/townlight/releases/tag/townlight-windows-v1.9.3.2) contains the signed MSI, corresponding source, checksums, signing evidence, and acceptance. The MSI SHA-256 is `b00510e0649552b5efd9744513bf9fcaf59cbee5755fd864eb922a5151c96b77`; its [acceptance summary](https://github.com/townlight/townlight/releases/download/townlight-windows-v1.9.3.2/ACCEPTANCE-Windows-1.9.3.2.md) names the tested artifacts and limits.

Windows 1.9.3.2 ships 17 components: Core platform plus 16 functional components: Records, Meetings, Code, Access, Notice, Zoning, Planning, Permitting, Inspections, Station, Boards, Contracts, Procurement, Data, Budget, and Grants. The coordinated documentation set has 18 manuals (Suite plus 17 component manuals). The current reference kit includes 12 manual PDF/Word pairs; no claim is made that every manual is available in a new format.

Windows 1.9.3.2 passed exact signed fresh-install, lifecycle, and adjacent-upgrade checks, including the tested direct upgrade from 1.9.3.1 to 1.9.3.2: back up data/settings, close the app, run the MSI, and reopen the same account/profile. Earlier evidence is retained. Acceptance records scope and limits; these checks do not imply that every workflow was retested.

Shared host/workstation configuration and separate portal configuration remain explicit, using existing staff roles. Bundled Station can provision during first-run; a physical camera needs the user Windows device access session.

The [suite operating manual](https://townlight.github.io/manuals/suite.html) covers the coordinated products and supporting modules; the [staff guide](https://townlight.github.io/manuals/windows-staff-workflows.html) covers staff workflows. The previous signed [Windows 1.9.3.1 release](https://github.com/townlight/townlight/releases/tag/townlight-windows-v1.9.3.1) and its acceptance retain their original identities and evidence for optional history. Standalone CivicCast retains its own installation and data.
